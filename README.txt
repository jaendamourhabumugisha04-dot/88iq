88%IQ STUDENT WEBSITE
=====================
Files:
- index.html
- style.css
- script.js

This is a free static starter website. It works in a browser without a server.
To publish for free, upload these files to GitHub Pages or Cloudflare Pages.

Important:
The registration currently saves data only in the visitor's browser (localStorage).
For real student accounts, passwords, online marks, teacher/admin dashboard and a database,
a backend/database must be added.
